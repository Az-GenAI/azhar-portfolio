# Azharuddin Shaikh — Portfolio

A cinematic, interactive portfolio focused on AI transformation, knowledge operations, program intelligence, and enterprise delivery.

## Structure

- `app/` contains the maintainable React, TypeScript, Tailwind CSS, and Framer Motion source.
- The repository root contains the production build served by GitHub Pages.

## Local development

```bash
cd app
npm install
npm run dev
```

## Production build

```bash
cd app
npm run build
```

The live site is published at https://az-genai.github.io/azhar-portfolio/.
