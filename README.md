# Azharuddin Shaikh - Portfolio Website

This is a static, highly-performant personal portfolio website built with Vanilla HTML, CSS, and JavaScript.

## How to Host for FREE on GitHub Pages (Takes 3 Minutes)

Since this website is completely static (no complex backend servers required), you can host it for free on GitHub Pages and get a live URL immediately.

### Step-by-Step Instructions:

1. **Create a GitHub Account:** If you don't have one, sign up at [github.com](https://github.com).
2. **Create a New Repository:** 
   - Click the **"+"** icon in the top right and select **"New repository"**.
   - Name it something like `azhar-portfolio`.
   - Ensure it is set to **Public**.
   - Click **"Create repository"**.
3. **Upload the Files:**
   - On the next screen, click the link that says **"uploading an existing file"**.
   - Drag and drop the 3 files from this folder (`index.html`, `style.css`, `script.js`) into the box.
   - Click the green **"Commit changes"** button at the bottom.
4. **Enable GitHub Pages:**
   - Go to your repository's **Settings** tab.
   - On the left sidebar, scroll down and click on **Pages**.
   - Under the "Build and deployment" section, find the **Branch** dropdown menu.
   - Change it from "None" to **"main"** (or "master").
   - Click **Save**.
5. **View Your Live Website:**
   - It will take about 1-2 minutes for GitHub to build the site.
   - Refresh the Pages settings screen, and you will see a message at the top saying: 
     *"Your site is live at https://[your-username].github.io/azhar-portfolio"*
   - Click that link to see your stunning new website live on the internet!

You can now put that URL on your resume and LinkedIn profile!
